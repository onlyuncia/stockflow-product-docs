# Шрифты PDF

`Ubuntu-R.ttf` и `Ubuntu-B.ttf` - шрифты семейства Ubuntu, включённые для воспроизводимой сборки русскоязычного PDF. Файлы взяты из установленного набора Poppler. Разрешение на использование и распространение приведено в [LICENSE.txt](LICENSE.txt); копия текста лицензии получена из [Google Fonts](https://github.com/google/fonts/blob/main/ufl/ubuntu/UFL.txt).

Шрифты используются при сборке и встраиваются в PDF. Браузерный интерфейс продолжает использовать системный шрифт.
